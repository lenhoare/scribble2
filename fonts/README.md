# Source skeleton fonts

Single-stroke SVG fonts from Evil Mad Scientist's collection (via the `hersheytext` npm package).
Converted to `src/data/skeletons.json` by `scripts/build-skeletons.mjs`.

- **EMS Elfin, EMS Readability, EMS Felix, EMS Allure** — Sheldon B. Michaels, SVG conversion by
  Windell H. Oskay. SIL Open Font License (http://scripts.sil.org/OFL).
- **Hershey Script 1-stroke** — The Hershey Fonts were originally created by Dr. A. V. Hershey
  while working at the U. S. National Bureau of Standards. The format of the Font data in this
  distribution was originally created by James Hurt, Cognition, Inc., 900 Technology Park Drive,
  Billerica, MA 01821 (mit-eddie!ci-dandelion!hurt). SVG conversion by Windell H. Oskay.
